# What is RFSS?

Hello, and welcome to this project, RFSS stands for Radio Frequency Signal Simulator, it is an open source software to generate synthetic electromagnetic waves and interference, and then it is turned into an exportable file that can be applied in machine learning or industrial proccesses. And it shows how accurate synthetic signals can get, in hopes to open up this field of synthetic signal generation.

This project is made mostly in C, and it is made to support a research project, which is titled "Synthetic RF Generation for Machine Learning and Industrial Automation".
